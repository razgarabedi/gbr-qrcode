# Digital Business Card QR Generator

Lokale React-Anwendung zur Erzeugung von vCard-QR-Codes und Hintergrundbildern.
Alle Daten bleiben im Browser — kein Backend, keine Cloud, kein Tracking.

## Entwicklung

```bash
npm install
npm run dev
```

## Prüfung

```bash
npm run typecheck
npm run build
npm test
```
